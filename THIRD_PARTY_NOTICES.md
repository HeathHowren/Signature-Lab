## x64dbg plugin SDK (not redistributed)

- Upstream: https://github.com/x64dbg/x64dbg
- `x64dbg-pluginsdk.zip` from the 2026.05.27 release, pinned by SHA-256 in
  `CMakeLists.txt`

The build compiles against the SDK's headers and links its import libraries,
so the plugin calls into x64dbg's own DLLs at run time. No x64dbg code is
copied into the plugin, and no part of the SDK ships in the release zip.

x64dbg is licensed under the GPLv3 with a clause on plugins, section 2 of its
`LICENSE`, which says the licence does not affect plugins that use x64dbg's
plugin interface and can only be run from x64dbg, and that such plugins may be
shared under their own licence. Signature Lab is such a plugin, which is why
it can be MIT.
